Conexão GitHub Online

Para cadastrar produtos, alterar preços e disparar varreduras direto pelo GitHub Pages (sem precisar do Mac ligado), você só precisa informar seu Token Pessoal do GitHub uma única vez neste dispositivo.

Passo 1: Como gerar seu token gratuito (30 segundos)
  1. Clique no botão abaixo para abrir a página de criação de tokens do GitHub.
  2. Marque as caixas repo (acesso ao repositório) e workflow (disparo de buscas).
  3. Role até o final e clique em Generate token. Depois copie o código gerado.
Abrir tela de criação de Token no GitHub
O token fica guardado com segurança apenas na memória do seu navegador neste dispositivo (localStorage).
